# Terraform `.gitignore` Standards

> Define the required Terraform-specific `.gitignore` entries for consumer repos and module repos. Existing `.gitignore` files across TUPSS Terraform repos are the default Visual Studio template with little to no Terraform-specific content — this standard closes that gap.

## Consumer Repos (`TUPSS.*.Terraform`)

```gitignore
# Terraform
**/.terraform/*
*.tfstate
*.tfstate.*
.terraform.tfstate.lock.info
crash.log
crash.*.log
override.tf
override.tf.json
*_override.tf
*_override.tf.json
.terraformrc
terraform.rc

modules/
```

**Do not add `*.tfvars` to this list.** TUPSS consumer repos track `.tfvars` files normally, per environment (e.g. `dev.tfvars`, `prod.tfvars`). They do not contain secrets — secrets are injected via token replacement at pipeline runtime, not stored in `.tfvars`. This is a deliberate deviation from the canonical Terraform `.gitignore` template (which typically ignores `.tfvars` as a secrets precaution), not an oversight.

**Do not add `.terraform.lock.hcl` to this list.** It must be committed — see [provider-version-management.md](./provider-version-management.md).

`modules/` is ignored here because consumer repos never hold real module source — it exists only as a temporary local copy used for `terraform validate` or lock file generation, and must never be committed.

## Module Repo (`TUPSS.Terraform`)

```gitignore
# Terraform
**/.terraform/*
*.tfstate
*.tfstate.*
.terraform.tfstate.lock.info
crash.log
crash.*.log
override.tf
override.tf.json
*_override.tf
*_override.tf.json
.terraformrc
terraform.rc
```

Same list as consumer repos, minus the `modules/` line — `modules/` in this repo **is** the real source of truth and must never be ignored.

## Rationale for Each Entry

| Entry | Why |
|---|---|
| `**/.terraform/*` | Local provider plugin cache and module cache — never portable, always regenerated by `init` |
| `*.tfstate`, `*.tfstate.*` | State files — TUPSS uses remote (`azurerm`) backends exclusively; a local state file appearing at all indicates a misconfigured backend and should never be committed |
| `.terraform.tfstate.lock.info` | Transient lock info file created during `terraform apply` — local-only, cleared on completion |
| `crash.log`, `crash.*.log` | Terraform crash logs — local debugging artifacts only |
| `override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json` | Terraform's built-in override mechanism — used for local experimentation only, never intended to ship |
| `.terraformrc`, `terraform.rc` | Local CLI configuration (e.g. credentials, plugin mirror settings) — machine-specific, never shared |
| `modules/` *(consumer repos only)* | Temporary local copy of module source used for validation/testing — never real content in a consumer repo |
